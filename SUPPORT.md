# Support

For setup questions and reproducible bugs, [open an issue](https://github.com/faraa2m/agent-desk/issues/new/choose). Include your macOS and Node.js versions, the command you ran, expected behavior, and sanitized error output.

Check the [README](README.md) first. If startup fails, inspect `~/.agent-desk/server.log` (or your configured state directory) and verify `claude` is on PATH. Remove private paths, prompts, tokens, and terminal content before sharing logs.

This is a community-maintained project with no support SLA. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
